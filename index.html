Current research work

Two-Stage Framework for Concept Difficulty Estimation and Prerequisite Validation in MOOCs

I built an end-to-end pipeline on the MOOCCubeX dataset (Computer Science subset) to address missing concept dependencies in MOOCs.

Stage 1
Predicted prerequisite relations between 919 concept pairs using only video interaction behaviour: pause, seek, rewatch, playback speed, watch time, and completion rate. Logistic Regression reached 86.41% accuracy, ahead of Random Forest (77.72%) and GNN (69.57%).
Stage 2
Introduced a heuristic difficulty score, D = (2R + 0.5S + 0.8P) / V, and grouped 458 concepts into Easy, Medium, and Hard with K-Means (Silhouette 0.55, K=3). I then checked that 52.1% of prerequisites (479 of 919) follow a valid easy-to-hard progression.
Outcome
The work shows that behaviour signals alone carry strong prerequisite information, which can support data-driven learning path recommendations.
Tools
Python, MOOCCubeX, K-Means, Logistic Regression
